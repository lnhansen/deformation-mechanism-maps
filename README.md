# Deformation Mechanism Maps

Interactive deformation mechanism maps for olivine, built for the Rock and Mineral Physics Laboratory, University of Minnesota. Single-file web app (`index.html`), no dependencies.

Flow laws: Hirth & Kohlstedt (2003), Hansen et al. (2011), Mei et al. (2010), Hiraga (2026 Treatise update), and the Breithaupt et al. (2023) dislocation model. All parameters editable; any power law or Peierls law can be added.
